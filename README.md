# Academic Transcripts and Course Descriptions

This repository contains supplementary academic documents relating to my studies in Computer Software and Computer Engineering (Software).

The repository includes course lists, academic transcripts, and course descriptions for the following qualifications:

- **Associate Degree:** Computer – Computer Software
- **Bachelor's Degree:** Computer Software Technology Engineering (discontinuous / consecutive pathway following the Associate Degree)
- **Master's Degree:** Computer Engineering – Software

The course descriptions provide information about the subjects covered in the courses, while the academic transcripts document the course titles, grades, and credits awarded by the respective institutions.

These materials are provided as supporting documentation for the assessment of my previous academic studies and subject-specific qualifications in applications for postgraduate programmes in **Artificial Intelligence, Computer Science, and related fields**.

**Important note on credits:** The credit values shown in the academic documents are the original Iranian university credit units, not ECTS. The academic institutions reviewing the application may determine the appropriate equivalence.

- **Bachelor's Degree:** Karaj Girls Technical and Vocational College, Karaj, Iran
